          怎么拿到账号文件？使用中遇到问题？
          

            
怎么登录：推荐直接用上面的「开始微信登录」：确认电脑微信已登录，点开始，然后在微信里重新打开游戏并进入主界面。抓包只在你自己的电脑上进行，登录成功后会生成账号文件并自动进入控制台。

            
会不会装东西：首次使用会往「当前用户」的受信任根证书里装一张本机测试证书（Windows 可能弹出安全警告，点「是」），用来在本机解密游戏登录；不需要管理员权限。不用了可以在登录页点「移除本机测试证书」。

            
账号文件：抓到或导入的账号保存在本机 work/accounts，登录页可以随时切换。文件里是一次登录的凭证，过期后重新用「微信登录」抓一次即可。

            
能放多个账号：不同账号的文件都拖进来会分别保存，登录页可以随时切换，互不影响。

            
怎么开启挂机：双击 exe 就能直接领奖、升级和自动挂机，不需要额外的启动脚本。

            
等级不一样也能用：没解锁的模块会标注「未解锁」；条件不满足的动作会自动跳过，不会报错，也不需要改配置。

            
安全提醒：账号文件等同于登录凭证，不要发到群里或公开。写操作会真实改动账号数据，请自行判断使用。

开始使用

              

                

                  
1. 微信登录（推荐）

                  
确认电脑微信已登录 → 点登录页的「开始微信登录」→ 在微信里把游戏完全关闭后重新打开并进入主界面。抓到登录后会自动保存账号并进入控制台。首次使用会安装本机测试证书，Windows 弹出安全警告时点「是」即可，不需要管理员权限。

                

                

                  
2. 也可以导入账号文件

                  
已经有 capture.json（比如从别的电脑抓好拷过来）时，点右上角「切换账号」，把文件拖进虚线框或点「选择文件」。登录页的「打开账号目录」可以直接查看本机已保存的账号文件。

                

                

                  
3. 进入并勾选

                  
在账号列表点「进入」，先在顶部选择只读或可写。打开「操作」页，按分类查看动作与解锁原因；只有已解锁且允许自动的动作可以勾选。勾选后手动开启自动挂机，或点「立即执行一轮」。征战推图和建筑升级需单独手动确认。

                

              

            


            

              
微信登录是怎么工作的

              

                
    
                  
  • 游戏小游戏没有独立的扫码登录接口，所以面板会在本机开一个只针对游戏域名的解密代理，读出电脑微信里小游戏的登录报文。
    • 
                  
  • 首次使用会把一张本机测试证书加入「当前用户」的受信任根证书，Windows 弹出安全警告时点「是」。不需要管理员权限。
    • 
                  
  • 整个抓包只在本机进行，报文不经过任何第三方服务器；结束后自动还原系统代理。
    • 
                  
  • 不用了可以在登录页点「移除本机测试证书」，或到「管理用户证书」里手动删除。
    • 
                  
  • 如果一直抓不到：确认电脑微信已登录、游戏是重新打开的、没有开其它代理/VPN 软件；也可以先点「取消」，再重新开始一次。
    • 
                

              

            


            

              
操作模式

              

                
    
                  
  • 面板选择：顶部可直接选择只读 / 可写，以服务器推送状态为准。切换模式不会自动恢复挂机。
    • 
                  
  • 只读硬锁：命令行加 --read-only 启动时，面板不能切换为可写；暂停 / 关闭自动仍可操作。
    • 
                

                
面板地址是 http://127.0.0.1:8848，窗口关掉后服务也会停止。

              

            


            

              
所有账号、所有等级

              

                
    
                  
  • 接口来自游戏客户端本身，角色、等级、区服不同不影响使用，多账号可以分别导入。
    • 
                  
  • 未解锁的模块照常显示并标注「未解锁」，不是错误。
    • 
                  
  • 动作列表显示服务器返回的解锁状态与原因。未解锁或状态待确认时不能加入自动计划；执行结果和失败原因以服务器返回为准。
    • 
                  
  • 低等级号建议只勾选「任务、邮件、挂机结算、离线收益」这些基础项；高等级号可以再勾集市、管家、科技、奇观等。
    • 
                

              

            


            

              
推荐的必做日常

              

                
    
                  
  • 任务领奖、每日任务宝箱、主线领奖
    • 
                  
  • 邮件一键领取
    • 
                  
  • 挂机资源结算、离线收益结算、收取建筑产物
    • 
                  
  • 活动奖励（全部可领）与免费礼包
    •

常见问题

            

              
一直显示离线 / 登录被拒绝？账号凭证过期了，或这个账号已经在别的设备登录。回到登录页重新用「微信登录」抓一次即可。

              
点了执行没反应？先看顶部连接和操作模式，再看动作的解锁状态及页面错误提示。只读时可在顶部切换；若显示启动参数硬锁，需去掉 --read-only 重启。

              
会不会和手机上的游戏冲突？同一账号同时登录可能互相顶下线，建议只在挂机时使用。

              
「全部协议」怎么用？那是从客户端里整理出的全部协议，给进阶玩家排查用。普通玩家只需要用上方精选动作；协议默认不勾选，参数不确定时不要执行。

              
数据会上传吗？不会。所有请求都从本机直接发往官方游戏网关，账号文件只存在本机 work 目录。

            

          


          

            
安全提醒

            

              
capture.json 里包含你的登录凭证，等同于账号密码，不要发到群里或公开。写操作会真实改动账号数据（消耗资源、领取奖励等），请自行判断是否使用，并遵守游戏规则。
