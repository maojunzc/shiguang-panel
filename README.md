# 时光大爆炸 · 本地挂机面板

一个在 Windows 本机运行的《时光大爆炸》小游戏面板：可以在面板里直接完成微信登录，查看角色、资源、任务，并按需执行日常操作和自动挂机。

> 所有数据只保存在你自己的电脑上，仓库不包含任何人的微信登录信息或账号数据。

## 功能

- **微信登录**：在面板里点「开始微信登录」，按提示重新打开微信里的游戏，自动抓取登录凭证并保存账号，不需要手动找抓包工具。
- **角色总览**：昵称、等级、区服、资源、属性、任务、建筑、活动等分页展示。
- **自动挂机**：任务领奖、每日宝箱、主线领奖、邮件领取、挂机结算、离线收益、收取建筑产物、活动奖励等可勾选。
- **全等级通用**：未解锁的模块会标注「未解锁」，条件不满足的动作自动跳过，不区分低等级/高等级账号。
- **多账号**：不同账号分别保存，登录页随时切换。
- **可选只读**：启动时加 `--read-only`，只查看数据，不发送任何写操作。

## 快速开始

### 方式一：直接运行源码（需要 Node.js 22+）

```bash
npm install
npm start
```

`npm start` 会自动在本地生成抓包用的测试证书（文件不会提交到仓库），然后打开 <http://127.0.0.1:8848>。

### 方式二：打包成单文件 exe

```bash
npm install
npm run build:exe
```

产物在 `dist/时光大爆炸面板.exe`，双击即可运行，浏览器打开 <http://127.0.0.1:8848>。打包过程会把 `public/` 和空的 `work/` 一起放到 exe 旁边；不会带上你自己的账号数据。

### 微信登录步骤

1. 在电脑上登录微信（要挂机的那个号）。
2. 打开面板，点「开始微信登录」。
3. 首次使用会把一张本机测试证书加入「当前用户」的受信任根证书，Windows 弹出安全警告时点「是」即可，不需要管理员权限。
4. 在微信里把游戏完全关闭后重新打开，进入游戏主界面。
5. 面板自动抓到登录、保存账号并进入控制台。结束后会自动还原系统代理。
6. 不想再使用时，在登录页点「移除本机测试证书」。

原理：游戏小游戏没有独立的扫码登录接口，面板会在本机启动一个只针对游戏域名（`*.y55l6.com`）的解密代理，从电脑微信里读出登录报文。报文只在本机处理，不经过任何第三方服务器。

## 数据与隐私

下面这些内容都已经在 [.gitignore](.gitignore) 中排除，不会被提交：

| 路径 | 内容 |
| --- | --- |
| `work/` | 账号凭证、抓包结果、设置、代理备份 |
| `certificates/` | 构建期生成的测试证书（含 CA 私钥） |
| `src/capture/certs.mjs` | 内嵌到 exe 的证书内容，由构建脚本自动生成 |
| `dist/`、`build/`、`*.exe` | 构建产物 |

每个人下载源码后，`npm run build:exe` 或 `npm start` 都会在自己的电脑上重新生成一套测试证书，互不影响。请不要把自己的 `work/` 目录、`capture.json` 或 exe 上传到公开仓库，它们等同于账号登录凭证。

## 项目结构

```text
src/
  server.mjs          本地 HTTP 服务与页面接口
  client.mjs          游戏网关 WebSocket 客户端（登录/心跳/请求）
  msgpack.mjs         msgpack 编解码
  actions.mjs         动作白名单与执行
  activities.mjs      活动配置
  protocols.mjs       客户端协议清单
  capture/
    proxy.mjs         本机 MITM 代理（仅解密游戏域名）
    session.mjs       微信登录抓包会话
    system.mjs        Windows 系统代理与证书操作
    certs.mjs         构建期生成的证书（不提交）
public/index.html     面板页面（登录、概览、操作、说明）
tools/
  gen-certs.mjs       生成测试证书
  build-exe.mjs       打包单文件 exe
```

## 命令行参数

```text
node src/server.mjs [--capture work/capture.json] [--port 8848] [--read-only] [--auto] [--interval 300]
```

- `--read-only`：只读模式，所有写操作被拦截。
- `--auto`：启动后自动登录默认账号并按间隔执行勾选动作。
- `--interval`：自动挂机间隔秒数，默认 300。

## 常见问题

- **一直离线 / 登录被拒绝**：凭证过期或账号已在别处登录，回到登录页重新用「微信登录」抓一次。
- **抓不到登录**：确认电脑微信已登录、游戏是重新打开的、没有开其它代理或 VPN；点「取消」后重试。
- **按钮是灰的**：启动时加了 `--read-only`，去掉该参数重启即可。
- **端口被占用**：换一个端口，例如 `--port 8849`。
